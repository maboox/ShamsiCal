# شمسی‌کَل

مجموعه‌ای از ویجت‌های مستقل و سبک روی دسکتاپ: تقویم شمسی، نقل‌قول، یادداشت و خبرخوان. هرکدام بدون قاب معمول پنجره، جداگانه جابه‌جا، کوچک یا پنهان می‌شود و جای خود را ذخیره می‌کند. تاریخ میلادی و قمری کنار تاریخ شمسی قرار دارند. برای تقویم و یادداشت، به اینترنت یا حساب کاربری نیاز ندارید.

![رابط واقعی فارسی با پوستهٔ آبی اقیانوسی](docs/images/widgets-fa.png)

## امکانات

- ویجت کوچک روزانه، همراه با ویجت ماهانهٔ اختیاری با شروع هفته از شنبه، شمارهٔ میلادی هر روز، جابه‌جایی روز و ماه و رفتن به تاریخ دلخواه.
- تاریخ قمری بر اساس ام‌القری؛ ممکن است با رؤیت محلی هلال تفاوت داشته باشد.
- یادداشت‌های چندگانه، متن پررنگ و مورب، فهرست کارها، ذخیرهٔ خودکار و پشتیبان آخرین ذخیره.
- خبرخوان RSS و Atom با منبع دلخواه HTTPS؛ دریافت فقط با درخواست شما و بدون قفل‌کردن رابط.
- خلاصهٔ فارسی اختیاری با Together AI، با تأیید شما برای هر درخواست.
- پوستهٔ آبی تیره و روشن، وزیرمتن داخل برنامه، آیکون‌های هماهنگ، اندازهٔ نوشتهٔ قابل تغییر و نمای جمع‌وجور.
- رابط فارسی راست‌به‌چپ و انگلیسی چپ‌به‌راست؛ تغییر زبان از تنظیمات.

## نصب روی ویندوز

۱. از [صفحهٔ انتشار](https://github.com/maboox/ShamsiCal/releases/latest)، فایل `ShamsiCal-2.1.0-windows-x64.zip` را دریافت کنید.

۲. همهٔ محتوای فایل را از حالت فشرده خارج کنید.

۳. فایل `ShamsiCal.exe` را در پوشهٔ `ShamsiCal` اجرا کنید. پوشهٔ `_internal` باید کنارش بماند.

نیازی به نصب پایتون نیست. ویندوز ۱۰ یا ۱۱، نسخهٔ ۶۴بیتی لازم است. فایل اجرایی امضای دیجیتال ندارد؛ قبل از اجرا SHA-256 آن را با فایل checksum همراه نسخه مقایسه کنید.

## اجرا از کد

پایتون ۳٫۱۱ یا جدیدتر لازم است:

</div>

```console
git clone https://github.com/maboox/ShamsiCal.git
cd ShamsiCal
python -m venv .venv
.venv\Scripts\activate
python -m pip install --require-hashes -r requirements.lock
python -m pip install --no-deps .
python -m shamsical
```

در لینوکس و مک برای فعال‌سازی محیط از `source .venv/bin/activate` استفاده کنید. راه‌انداز قدیمی `shamsi_calendar_widget.pyw` هم کار می‌کند.

## استفادهٔ روزمره

تقویم و نقل‌قول به‌صورت پیش‌فرض روی دسکتاپ ظاهر می‌شوند. از نوار بالای هر ویجت آن را بکشید و با گوشهٔ پایین اندازه‌اش را تغییر دهید. از منوی سه‌نقطه، راست‌کلیک یا آیکون کنار ساعت ویندوز، یادداشت و خبرخوان را جداگانه باز یا پنهان کنید. جای همهٔ ویجت‌ها مستقل ذخیره می‌شود. تنظیمات، پس‌زمینهٔ شفاف، وضوح و حالت همیشه‌بالا را هم در اختیارتان می‌گذارد.

روز را از جدول انتخاب کنید؛ جزئیات کنارش به‌روز می‌شود. دکمه‌های بالای جدول ماه را عوض می‌کنند. «رفتن به تاریخ» تاریخ شمسی با اعداد فارسی یا انگلیسی، مانند `۱۴۰۵/۰۷/۲۹` می‌پذیرد. «نمای جمع‌وجور» فقط تقویم روزانه را کوچک می‌کند؛ بقیهٔ ویجت‌ها مستقل باقی می‌مانند. نمای ماه از دکمهٔ تقویم باز می‌شود.

در یادداشت‌ها، یادداشت بسازید و عنوانش را با دکمهٔ تغییر عنوان یا دوبار کلیک عوض کنید. حذف نیاز به تأیید دارد. دکمهٔ فهرست کارها، خط فعلی را به مورد فهرست تبدیل می‌کند و با زدن دوباره، تیکش را تغییر می‌دهد. Enter مورد بعدی را می‌سازد.

در خبرخوان، نشانی HTTPS عمومی یک RSS یا Atom اضافه کنید و «تازه‌سازی» را بزنید. منبعی خودکار دریافت نمی‌شود. «خواندن در مرورگر» لینک اصلی را باز می‌کند.

| میانبر | کار |
| --- | --- |
| `Ctrl+T` | امروز |
| `Alt+Left` / `Alt+Right` | روز قبل / روز بعد |
| `Ctrl+J` | رفتن به تاریخ |
| `Ctrl+N` | یادداشت جدید |
| `Ctrl+S` | ذخیره |

## حریم خصوصی و اینترنت

برنامه حساب کاربری، تبلیغ، تله‌متری یا رهگیری ندارد. **یادداشت‌ها روی همین دستگاه و بدون رمزگذاری ذخیره می‌شوند**؛ فایل پشتیبان هم متن معمولی است. دستگاه و فایل‌های خروجی را امن نگه دارید.

مناسبت آنلاین در شروع خاموش است. با فعال‌کردن آن، تاریخ انتخاب‌شده و IP شما برای pnldev ارسال می‌شود. مناسبت‌ها ممکن است ناقص یا غیررسمی باشند؛ برای تصمیم رسمی از مرجع معتبر بررسی کنید. دریافت ناموفق به‌عنوان «روز بدون مناسبت» ذخیره نمی‌شود.

منابع فقط HTTPS عمومی هستند. مقصدهای محلی و خصوصی، فایل محلی، پورت سفارشی و لینک دارای نام کاربری یا رمز پذیرفته نمی‌شوند. خبرها به‌صورت متن نمایش داده می‌شوند و تصویر رهگیری بارگذاری نمی‌شود. پس از بازکردن لینک، سیاست‌های مرورگر و سایت مقصد اعمال می‌شوند.

## خلاصهٔ اختیاری با هوش مصنوعی

پیش از اجرای برنامه، متغیرهای محیطی `TOGETHER_API_KEY` و `SHAMSICAL_AI_MODEL` را تنظیم کنید؛ نام یک مدل فعال در Together را انتخاب کنید. کلید در برنامه یا پشتیبان ذخیره نمی‌شود. آن را در ریپو یا گزارش خطا نگذارید.

دکمهٔ خلاصه، پس از تأیید، فقط عنوان و چکیدهٔ همان خبر را برای Together AI می‌فرستد؛ یادداشت‌ها ارسال نمی‌شوند و متن کامل مقاله دریافت نمی‌شود. استفاده ممکن است هزینه داشته باشد و خروجی ممکن است نادرست باشد.

## مهاجرت و پشتیبان

نسخهٔ ۲٫۱ رفتار اصلی ویجت‌های مستقل را برمی‌گرداند و یادداشت‌ها و منابع نسخهٔ ۲٫۰ را حفظ می‌کند. نسخهٔ ۱ فضای ذخیرهٔ جداگانه دارد و تنظیماتش دست‌نخورده می‌ماند. در تنظیمات، «ورود یادداشت‌های نسخهٔ ۱» را بزنید. فقط یادداشت‌ها افزوده می‌شوند؛ کلید وارد نمی‌شود. دکمهٔ جداگانهٔ «بازیابی چیدمان ویجت‌های نسخهٔ ۱» جای ویجت‌ها و وضعیت نمایش قبلی را برمی‌گرداند.

نسخهٔ قبلی کلید Together را به‌صورت متن ساده ذخیره می‌کرد. «پاک‌کردن کلید ذخیره‌شدهٔ نسخهٔ ۱» آن مقدار را حذف می‌کند؛ اگر از کلید استفاده کرده‌اید، در Together هم آن را تعویض کنید. این کار حذف از پشتیبان‌های قدیمی دستگاه را تضمین نمی‌کند.

در تنظیمات، خروجی پشتیبان بگیرید یا پشتیبان JSON معتبر را بازیابی کنید. بازیابی داده‌های فعلی را جایگزین می‌کند و دریافت آنلاین را خاموش نگه می‌دارد. فایل `workspace.json.bak` نسخهٔ قبلی ذخیرهٔ موفق است؛ جایگزین پشتیبان دوره‌ای نیست.

محل پیش‌فرض داده‌ها در ویندوز `%LOCALAPPDATA%\ShamsiCal\ShamsiCal` است. گزینهٔ `--data-dir` فضای جداگانه می‌سازد. اگر داده خراب باشد، برنامه آن را بازنویسی نمی‌کند؛ از پشتیبان بازیابی کنید یا فضای تازه بسازید. [جزئیات بازیابی](docs/USER_GUIDE.md#data-backups-and-migration).
